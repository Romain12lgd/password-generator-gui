# Password Generator (GUI)

A desktop application built with Python and Tkinter for generating secure, customizable passwords.

## Features

- **Customizable character sets:** Choose to include lowercase letters, uppercase letters, digits, and punctuation marks.
- **Security enforcement:** Enforces a minimum length of 8 characters.
- **Graphical user interface:** Built with Tkinter for a clean and intuitive user experience.
- **Clipboard integration:** Copy generated passwords directly to the clipboard.

## Technologies

- Python 3
- Tkinter
- Standard libraries: `random`, `string`

## Getting Started

1. Ensure Python 3 is installed on your system.
2. Download or clone the project files.
